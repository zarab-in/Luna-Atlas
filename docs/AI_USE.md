# AI Usage Statement


### IMPORTANT NOTICE: PROJECT IN PROGRESS
This document and its deliverables are currently under an early-stage conceptual prototype currently under development by Team Zarabin for the NASA Space Apps Challenge 2026.
The current build is strictly an initial **proof-of-concept** and does not reflect the final website deployment, data models, or the official 30-second submission video required for global judging. 
Full functional integration and video production still remain under progress.


As part of my commitment to project integrity, transparency, and the official guidelines of the NASA Space Apps Challenge, this statement outlines the exact use of human creativity, learning cycle, synthetic code generation, and AI-assisted research utilized across the project's development.


- **Research & Scientific Context (Perplexity AI)**: Used exclusively as a research assistant to discover relevant NASA terrain APIs, locate CLPS payload specifications, and cross-reference peer-reviewed models on Shackleton Crater rim lighting profile conditions, accessed by public NASA datasets.
- **Website Framework (Google Gemini & Bolt.diy)**: Used to rapidly generate base UI layouts, boilerplate component states, and modern Webpack/Vite deployment configurations. All auto-generated code was subsequently reviewed, refactored, and integrated manually.
- **Graphics, UI/UX & 3D Visualization**: Zero generative AI was utilized for design assets. Every vector graphic, color system, interface wireframe, user flow, and custom 3D rendering pipeline was authored manually using my years of experience in digital design and visualization. Software used include Adobe Photoshop, Illustrator, and Blender.
