#### About the Project
Project Name: Luna Atlas
Team Name: zarabin

#### Summary: 
Luna Atlas turns complex lunar terrain, illumination, and Earth-visibility data into an interactive mission-planning tool for answering one deceptively simple question: 
*“Where and when can we operate on the Moon?”*

#### The Problem
Imagine a CLPS lander touching down near the lunar south pole, where the science team wants to drill into a permanently shadowed crater. However, the engineering team needs to know: 
- Will the solar panels get enough light for the next 72 hours? 
- Can we talk directly to Earth, or do we need a relay? 
Right at that moment, answering those means using multiple software with complicated interfaces, all while the launch *time window ticks down*.

#### The Solution
Luna Atlas is an interactive mission‑planning tool that visualizes Sun and Earth positions over lunar terrain, so planners can compare landing sites and dates in seconds instead of hours.
